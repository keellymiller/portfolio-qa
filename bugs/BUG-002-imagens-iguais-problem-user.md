# BUG-002 - Todos os produtos aparecem com a mesma foto (usuário problem_user)

**Severidade:** Média (o cliente não consegue ver como é o produto)
**Usuário:** problem_user
**Ambiente:** Windows, navegador Edge
**Data:** 16/10/2026
**Status:** Confirmado (visto em dois navegadores/painéis)

## Passos para reproduzir
1. Abrir https://www.saucedemo.com
2. Entrar com o usuário `problem_user`
3. Olhar a lista de produtos

## Resultado esperado
Cada produto mostra a sua própria foto (a mochila mostra uma mochila, a camiseta mostra uma camiseta etc.).

## Resultado obtido
Todos os produtos mostram a mesma foto: um cachorro com uma bolinha de tênis na boca.

## Evidências
(anexar o print da lista de produtos)

## Observações
Com o usuário standard_user as fotos aparecem certas. O problema só acontece com o problem_user.
